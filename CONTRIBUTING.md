# Contributing

Bug reports, human code review and focused pull requests are welcome. Use English
for public issues, documentation and interface text.

Include device/Onion and release versions, location, action and relevant log lines.
Do not upload ROMs, BIOS, saves, copyrighted assets or randomized-ROM logs.
Screenshots help. Check the [limitations](README.md) first.

See [BUILD.md](BUILD.md) for builds and tests. Real-core tests must use a separate
app directory with explicit guards and a QA marker, never user saves. Explain
what a patch changes and the checks actually performed.

AI-assisted contributions are welcome with honest disclosure. Do not claim reviews
or tests that did not occur. Retain upstream credits/licenses and link new sources
in [SOURCES.md](SOURCES.md).
